## 카드 1 — [분류: 할 것] 해피콜완료 이탈 구간을 우선 점검한다

| 항목 | 내용 |
| --- | --- |
| 분류 | 할 것 |
| 근거 | 완료→해피콜완료 전환율 33.75%(33,067/97,973). 비교 대상: 직전 단계 98.76%. 격차 -65.01%p. 비중: 전체 이탈 인원의 65.43%(64,906명). 표본: 97,973건(한 건 흔들림 0.001%p) |
| 비용 | 미확인 |
| 효과 | 미확인 — 실측은 현재 상태값(33.75%)뿐이고, 개입 후 예상치는 추정도 되어 있지 않다 |
| 확신도 | 높음 — 표본이 매우 크고, 격차가 흔들림 폭보다 압도적으로 크다 |
| 크기 | 약 42.5 (격차 65.01%p × 비중 65.43%), 절대 이탈 64,906명 |
| 되돌림 | 가능 — 프로세스를 점검·조정하는 일이라 이전 방식으로 되돌릴 수 있다 |

## 카드 2 — [분류: 다시 할 것] 성과 편차가 큰 거래선을 개별 점검한다

| 항목 | 내용 |
| --- | --- |
| 분류 | 다시 할 것 |
| 근거 | 거래선코드 축으로 쪼개면 40개 중 19개(주의필요 10개·성공 9개)가 전체 평균(33.75%) 대비 ±1.0%p 이상 차이. 최저 CL-020 31.02%(672/2,166), 최고 CL-038 37.28%(844/2,264). 비중: 19개 거래선 물량이 전체의 46.67%(45,724/97,973건) |
| 비용 | 미확인 |
| 효과 | 미확인 — 왜 갈리는지 원인을 아직 모른다(9주차 Day1은 원인 조사 범위 밖) |
| 확신도 | 보통 — 차이가 있다는 것은 확인됐으나 원인은 미상이라 무엇을 어떻게 점검할지는 아직 정하지 않았다 |
| 크기 | 약 2.9 (최대 격차 6.26%p × 비중 46.67%), 대상 물량 45,724건 — 카드1 다음으로 크다 |
| 되돌림 | 가능 — 개별 점검은 조사 활동이라 되돌릴 대상 자체가 없다 |
