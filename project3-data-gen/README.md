# project3_growth 합성 데이터

7주차 Day1 교안이 배포한다고 안내한 `project3_growth` parquet 9개(강의 실제 데이터)를 받지
못해, 교안이 설명하는 구조적 특징을 그대로 갖도록 **합성으로 대체**했다.

- `generate_project3_growth.py` — 생성 스크립트. seed=42로 고정, 재실행하면 같은 데이터가 나온다.
- 출력: `../data/*.parquet` 9개

## 일부러 심은 것 (교안의 학습 포인트와 대응)

| 특징 | 교안 기댓값 | 이 데이터 |
|---|---|---|
| `customers.visitor_id` 결측 | 87% | 86.5% |
| `sessions.campaign_id` 결측 | 38% | 38.0% |
| `support_tickets.satisfaction_score` 결측 | 70% | 70.2% |
| 퍼널 병목 구간 | 신청시작→신청완료 | 신청시작→신청완료 (20.4% 전환, 가장 낮음) |
| EXP-003 SRM(불균형 배정) | 52.9:47.1 | 52.4:47.6 |

**이 데이터는 실제 강의 데이터가 아니다.** 행 수·정확한 결측 개수는 강의 기댓값과 다를 수
있고(예: 이 데이터는 143만 행, 교안 기댓값은 146만 행), 스키마 노트·프로파일 결과 등
project3-wiki에 기록하는 모든 실측값은 이 합성 데이터 기준이라는 점을 명시한다.
