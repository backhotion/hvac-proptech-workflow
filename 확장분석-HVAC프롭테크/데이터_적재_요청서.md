# 데이터 적재 요청서 — 지역별 영업지원×신축·거래 통합 현황

**수신**: 데이터팀 / 개발팀 (BigQuery 및 사내 시스템 접근 권한 보유 부서로 추정 — 정확한 담당 팀은 확인 필요)
**요청일**: 2026-07-26

## 이 데이터로 답하려는 질문

"우리 회사가 설치자재를 파는 지역에서, 그 동네에 새 건물이 얼마나 늘고 집이 얼마나 팔리는지를 같이 보고 싶습니다.
그리고 그게 우리 영업 실적(오주문·서비스 점수)과 관련이 있는지도 알고 싶습니다."

## 한 행은 무엇이고, 언제 기록되나

**한 행 = "이 동네(시군구) 이번 달(연월)의 상태 요약" 1건.** 매달 말, 그 달까지의 실적을 한 번씩 집계해서 새 행으로
쌓는 방식입니다(과거 행을 수정하지 않고 매달 새로 추가).

## 1단계 (최소) — 이것만 있어도 첫 질문에 답할 수 있음

| 컬럼명 | 의미 | 비고 |
|---|---|---|
| 시군구코드 | 어느 동네인지 | |
| 연월 | 언제(YYYYMM) | |
| 그 달 아파트 거래 건수 | 부동산 실거래 신고 건수 | |
| 그 달 신축 인허가 건수 | 새 건물 허가 건수 | |
| 우리 설치자재(SAC) 대상 신축 연면적 | 우리 제품이 들어갈 만한 신축 규모 | 기존 `영업지원-서비스분석.csv`에서 이미 계산 가능 |

## 2단계 (추가) — 나중에 여유 있을 때

| 컬럼명 | 의미 | 비고 |
|---|---|---|
| 그 달 평균 거래금액 | | |
| 전체 신축 연면적(SAC 무관) | | |
| 그 지역 상업용 전기사용량 | 현재는 시도 단위만 있어 근사치 | |
| 그 지역 거래선 평균 서비스 점수 | **지금은 만들 수 없음(아래 참고)** | |
| 그 지역 오주문율 | **지금은 만들 수 없음(아래 참고)** | |

## 지금 답할 수 없는 것 / 이 데이터가 생기면 답할 수 있게 되는 것

- **지금 답할 수 없는 것**: "오주문 많이 나는 지역이 실제로 신축·거래가 활발한 지역과 겹치는가?" — 우리 거래선(고객사)이
  어느 동네에 있는지 기록해 둔 데이터가 현재 없어서, 서비스 점수·오주문율을 지역과 연결할 방법이 없습니다.
- **이 표(1단계)가 생기면 답할 수 있게 되는 것**: "신축이 늘어나는 지역이 몇 달 뒤 실제 거래량 증가로 이어지는가?"
  같은, 지역 성장성과 관련된 질문들.
- **거래선-지역 매핑까지 추가로 생기면 답할 수 있게 되는 것**: 애초 원했던 질문 — "오주문·서비스 품질이 지역 특성과
  관련 있는가?" (이건 이번 요청과 별개로, 거래선 주소를 기록하는 작업이 먼저 필요합니다 — 아래 참고)

## 어디를 건드려야 할지 (추측, 확인 필요)

- 실거래가·신축 인허가 데이터: 이번에 별도로 수집한 `확장분석-HVAC프롭테크/data_*.csv` 활용 가능(공공데이터포털 API 기반)
- SAC 신축 연면적: 기존 `영업지원-분석/영업지원-서비스분석.csv`에 이미 있음
