## 3. 거래처마스터 직접 확인 가이드 (ERP 화면에서)

IT전산팀 답변을 기다리지 않고 본인 ERP 계정으로 바로 확인 가능한 절차:

1. ERP에 로그인해 **거래처 조회(또는 매출처/구매처 관리)** 메뉴를 연다.
2. 평소 담당하는 거래선 하나를 선택해 상세 화면을 연다.
3. 화면에 **주소/배송지/소재지**라는 이름의 필드가 있는지 확인한다.
4. 있다면:
   - 그 값이 "서울특별시 강남구 …" 처럼 **시군구까지 나오는지**, 아니면 "…로 123" 형태의 도로명주소 한 줄뿐인지 확인
   - 필드명을 정확히 메모 (예: "소재지", "배송지주소" 등 — 나중에 요청서에 그대로 쓸 수 있음)
5. 화면 상단·하단에 **엑셀 다운로드/내보내기 버튼**이 있는지 확인 (있으면 거래처 전체를 한 번에 받을 수 있음)
6. 위 내용을 아래에 기록:

```
필드명:            (예: 소재지)
시군구 구분 여부:    (예/아니오)
샘플 값:           (예: 서울특별시 강남구 테헤란로 123)
엑셀 다운로드 가능:   (예/아니오)
```
